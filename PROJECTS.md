## 🛠️ Flagship Open Source & Platforms

### 1. Kitwork Engine (`kitwork`)
- **Category**: Sovereign Web Runtime & Logic Engine
- **Tech Stack**: Go, Hand-written Stack VM, JavaScript Subset Runtime, SQLite WAL
- **Repository**: [github.com/kitwork/core](https://github.com/kitwork/core)
- **Description**: A multi-tenant Go host running a small JavaScript subset compiled to bytecode executed on a hand-written Go VM (Zero V8 dependency).

### 2. Build in Public Hub (`theinpublic.com`)
- **Category**: Master Knowledge Hub & Community Portal
- **Live Site**: [theinpublic.com](https://theinpublic.com)

- **Description**: A 26-module first-principles guide for indie hackers, bootstrappers, unit economics, pricing strategies, and open startups.

### 3. SEOER.AI Search Engineering (`seoer.ai`)
- **Category**: Generative Engine Optimization (GEO) & Search Engineering Spec
- **Live Site**: [seoer.ai](https://seoer.ai)
- **Repository**: [github.com/seoerai/seo](https://github.com/seoerai/seo)
- **Description**: An engineering specification covering AI answer engine citation models, RAG vector retrieval, Core Web Vitals, and JSON-LD microdata.

### 4. Lofi With Me (`lofiwithme.com`)
- **Category**: Productivity & Ambient Sound Space

# reference

Short reference entries on computing terms.

These were generated from a term list, not written by me.

They are kept because a lookup table is still useful, and because deleting work
is not the same as being honest about it.

What they are not:

```text
they are not the concepts
they are not what I learned
```

The notes I wrote by hand live in [concepts](../concepts/README.md), in the order
I needed to learn them. Read those instead.

## Categories

- [ai](./ai) — models, agents, prompting, memory
- [cloud](./cloud) — infrastructure, scaling, pipelines
- [databases](./databases) — trees, transactions, storage
- [general](./general) — general computing terms
- [networking](./networking) — routing, bandwidth, brokers
- [programming](./programming) — algorithms and patterns
- [runtime](./runtime) — runtime and execution terms
- [security](./security) — access, authentication, safety

## If you are wondering why they are here

I generated them while working out how to publish a concept collection.

They taught me something I did not expect: volume reads as filler, and a reader
can tell within two entries.

The thirty notes in [concepts](../concepts/README.md) took much longer and are
worth more.

I am leaving these here rather than quietly deleting them, because that
difference is the whole lesson.

# Hướng Dẫn Đóng Góp (Contributing Guidelines)

Cảm ơn bạn đã quan tâm đóng góp cho repository **Build In Public (BiP)**! Cộng đồng phát triển nhờ sự chia sẻ và đóng góp từ chính các Makers.

---

## 🛠️ Bạn có thể đóng góp những gì?

1. **Thêm Mẫu (Templates)**: Các mẫu bài đăng, quy trình làm việc, checklist chưa có trong repo.
2. **Cập nhật danh sách Open Startups & Tools**: Thêm các dự án Open Startup truyền cảm hứng hoặc các công cụ hỗ trợ BiP mới.
3. **Cải thiện Tài liệu (Docs)**: Bổ sung kiến thức về bảo mật, chiến lược nội dung, kỹ thuật đo lường chỉ số.
4. **Sửa lỗi & Định dạng**: Chỉnh sửa lỗi chính tả, cải thiện cú pháp Markdown, broken links.

---

## 📋 Quy trình gửi Pull Request (PR)

1. **Fork** repository này về tài khoản GitHub của bạn.
2. **Clone** repo fork về máy cá nhân:
   ```bash
   git clone https://github.com/your-username/build-in-public.git
   ```
3. Tạo một branch mới cho tính năng / thay đổi của bạn:
   ```bash
   git checkout -b feature/add-new-template
   ```
4. Thực hiện các chỉnh sửa và commit với thông điệp rõ ràng:
   ```bash
   git commit -m "feat: add indie maker content calendar template"
   ```
5. Push branch lên repo fork của bạn:
   ```bash
   git push origin feature/add-new-template
   ```
6. Mở một **Pull Request** mới vào branch `main` của repository gốc và mô tả chi tiết thay đổi của bạn.

---

## 📐 Quy chuẩn viết Markdown

- Trình bày mạch lạc, sử dụng đúng cú pháp GitHub Flavored Markdown (GFM).
- Giữ cho văn phong tích cực, cầu thị, rõ ràng và dễ tiếp cận đối với cả những người mới bắt đầu (Beginners).
- Kiểm tra liên kết (links) để đảm bảo không có link hỏng trước khi gửi PR.

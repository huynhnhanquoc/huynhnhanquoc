# info

Structured profile data, in YAML rather than prose.

The rest of this repository is written to be read by a person. These files hold
the same facts in a shape a program can consume, so a site, a feed, or an agent
does not have to parse a README to answer a simple question.

- [about.yml](about.yml) — name, location, role, working philosophy.
- [contact.yml](contact.yml) — the one address that reaches me.
- [social.yml](social.yml) — accounts, by platform.
- [projects.yml](projects.yml) — active projects with stack and category.
- [domains.yml](domains.yml) — the full domain portfolio, grouped by purpose:
  personal brand, the Kitwork ecosystem, build-in-public, and products.
- [stack.yml](stack.yml) — languages, databases, and frontend approach.
- [donate.yml](donate.yml) — sponsorship links.

Prose and data drift apart quickly. When these disagree with the
[README](../README.md), the README is the one that was updated by hand and the
one to trust; the mismatch is a bug in this folder.
